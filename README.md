One word an ex would use to describe the entrant: **rebound**. One word reframes the whole relationship as a pit stop — never the destination, just the layover on the way back to someone else. The program validates the word against the gate (1–24 characters, exactly one word, a painful truth rather than a pure insult) and writes it to `/output/entry.txt`.

> rebound

## Run it

```sh
node main.ts
```
